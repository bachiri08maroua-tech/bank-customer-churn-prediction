# Bank Customer Churn Prediction 🏦

Predict which bank customers are likely to leave using Machine Learning.

## 📊 Project Overview
- Dataset: 10,000 bank customers
- Goal: Predict customer churn
- Best Model: Random Forest

## 🏆 Results
| Model | Accuracy |
| --- | --- |
| Random Forest | 86.4% |
| Logistic Regression | 81.1% |

## 🔍 Key Insights
- Age is the #1 factor driving churn
- Germany has the highest churn rate
- Female customers churn more than male customers
- Customers with high Balance are more likely to leave

## 🛠️ Tools Used
Python, Pandas, Matplotlib, Scikit-learn
